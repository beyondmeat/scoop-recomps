# Recomps Scoop Bucket

This is a [Scoop](https://scoop.sh) bucket for recomps. It's focused on Windows recomps.

For other recomps, games, and other apps, check out [scoop-games](https://github.com/Calinou/scoop-games) or other scoop buckets.

Interested in adding something? To add a new recomp, please read the [Contributing Guide](./CONTRIBUTING.md).

## Installation and Usage

**[Click here for the full installation guide (INSTALL_SCOOP.md)](./INSTALL_SCOOP.md)** to learn how to:

- Install Scoop on Windows
- Add this bucket
- Install and update recomps
- Setup automated updates
